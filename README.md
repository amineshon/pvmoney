# پی‌وی‌مانی

اپ مدیریت دارایی شخصی: حساب‌های بانکی و کیف پول، پروژه‌های هدف‌دار، درآمد و هزینه.

رابط کاربری فارسی و راست‌به‌چپ است. مبالغ به **تومان** ذخیره می‌شوند و می‌توانی با واحد هزار / میلیون / میلیارد واردشان کنی.

## اجرا با داکر

از ریشه پروژه:

```bash
docker compose up --build
```

بعد در مرورگر:

- فرانت: [http://localhost:3000](http://localhost:3000)
- API: [http://localhost:8080/health](http://localhost:8080/health)

Postgres داخل شبکه داکر بالا می‌آید و لازم نیست پورت ۵۴۳۲ روی سیستم باز باشد.

## توسعه محلی

۱. Postgres را بالا بیاور (یا فقط سرویس `db` را با داکر):

```bash
docker compose up db -d
```

۲. بک‌اند Go:

```bash
cd backend
go run ./cmd/server
```

متغیرهای محیطی اختیاری:

- `DATABASE_URL` پیش‌فرض: `postgres://pvmoney:pvmoney@localhost:5432/pvmoney?sslmode=disable`
- `PORT` پیش‌فرض: `8080`

۳. فرانت Next.js:

```bash
cd frontend
npm install
npm run dev
```

فرانت درخواست‌های `/api` را به بک‌اند پروکسی می‌کند (`API_URL`، پیش‌فرض `http://localhost:8080`).

## قابلیت‌ها

- **داشبورد:** ارزش خالص، موجودی نقد، پول قفل‌شده در پروژه‌ها، درآمد و هزینه ماه
- **حساب‌ها:** کارت بانکی، موجودی اولیه، تنظیم موجودی
- **پروژه‌ها:** تارگت مالی، واریز تدریجی از حساب، نوار پیشرفت، برداشت
- **تراکنش‌ها:** درآمد، هزینه، انتقال بین حساب‌ها
- **آمار:** نمودار ماهانه و دسته‌بندی هزینه‌ها

پول واریزی به پروژه از موجودی حساب کم می‌شود و در ارزش خالص جداگانه به‌عنوان «قفل در پروژه‌ها» دیده می‌شود. برای حذف پروژه اول باید موجودی‌اش را برداشت کنی.
